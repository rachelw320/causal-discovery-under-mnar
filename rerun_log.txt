A few things worth noting in the results.
Sachs GES baseline SHD=30 with zero variance - GES finds the same CPDAG every run because
the Sachs skeleton is very consistent at n=5000. Zero std is expected not a bug.
MCAR on Sachs shows SHD going down as missingness increases which looks odd but makes sense
because at very high MCAR so many rows get dropped that the algorithm returns a sparse graph
which by chance has lower SHD than the wrong dense graph it was learning before.
Asia GES MAR at 50% jumps to SHD=10.5 which is a big increase, expected given how much
data is lost to listwise deletion at that severity.
